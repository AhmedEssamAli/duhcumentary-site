Privacy policy

Last updated: 4 October 2026

This policy covers the Duhcumentary publishing tool ("the tool"), a private tool used only by the channel owner to upload and schedule videos to accounts owned by Duhcumentary.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What the tool accesses

  • Google / YouTube: permission to upload videos, set thumbnails and captions, add videos to playlists and update video details on the Duhcumentary channel only (YouTube Data API).
  • Meta: permission to publish videos and Reels to the Duhcumentary Facebook Page and Instagram account (Graph API).
  • TikTok: permission to read basic profile info and post videos to the Duhcumentary TikTok account (Content Posting API).

What it stores and how it is used

Only the access tokens for these owned accounts, plus the IDs and links of the videos it uploaded. Tokens are kept on the owner's own computer (or in encrypted secret storage when an automated runner is used), are used only to publish the owner's videos, and are never shared. The tool does not collect, store or process data about viewers or any other person. It places no cookies and runs no tracking.

Sharing

No data is sold or shared with third parties. Videos go only to the platforms listed above.

Revoking access and deleting data

Google access can be revoked at any time on the Google security settings page. Meta access can be removed in Facebook Settings > Business integrations, and TikTok access in TikTok Settings > Security > Manage app permissions. After access is revoked, the stored tokens are deleted within 7 days. To ask for any stored data to be deleted, email duhcumentary@gmail.com; it is deleted within 7 days.
